# 🛡️ FinGuard: AI Social Credit Risk Analyzer
A Full-Stack Machine Learning application that predicts financial reliability using alternative social media data features.

### 🚀 Features
ML Pipeline: Gradient Boosting Classifier trained on 5,000+ synthetic behavioral samples.

API-First Design: Scalable FastAPI backend with automated Swagger documentation.

Interactive UI: Real-time Streamlit dashboard for risk visualization and "AI Agent" narratives.

### 🛠️ Installation & Usage
pip install -r requirements.txt

Run Backend: python app.py

Run Frontend: streamlit run dashboard.py
